## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：`lora_r` を 16 → 4 に変更した（lr=2e-4、num_train_epochs=20、そのほかは同じ）。変えたあとにランタイムを再起動し、上から実行し直した。
- 結果（比較表や数字）：

  | 項目 | lora_r=16（元） | lora_r=4 |
  |---|---|---|
  | 学習パラメータの割合 | 0.842% | 0.212% |
  | format_rate（学習前 → 後） | 0.095 → 1.000 | 0.095 → 1.000 |
  | content_rate（学習前 → 後） | 0.000 → 0.905（19/21） | 0.000 → 0.857（18/21） |
  | 最終 loss | 0.0138 | 0.0132 |
  | 学習時間 | 250 秒 | 243 秒 |
  | 退行した質問 | 0 問 | 0 問 |

  - 学習パラメータは約 1/4 になったが、学習時間は約 3% しか変わらなかった。LoRA の追加部分（B A x）は、元の重みを通る計算（W₀x）の 1% 未満（4096×4096 の行列で r=4 なら約 0.2%、r=16 なら約 0.8%）で、計算の大半は固定された元の重みを通る部分だと考えられる。
  - content_rate の差（0.905 と 0.857）は 21 問中 1 問の差。1 回ずつの実行で、GPU 上の学習は seed を固定しても完全には再現しないため、r の違いによる差とは言えない。
  - 差が出た質問は「課題の文字数に制限はありますか」（FAQ に無い質問）。r=16 は「記載がありません」（needs_review: true）と答えたが、r=4 は提出形式の文を返して needs_review: false と断定した。
  - 内容の失敗は r=4 で 3 問、r=16 で 2 問。すべて「根拠なしの質問に、FAQ の別の項目の文を当てて断定する」型で、根拠あり 15 問は両方とも全問正解だった。知識を問う質問 4 問の分類は 2 つの条件で同じだった。
  - 比較に使った `result.json` は `lectures/02/` に置いた（lora_r4・lora_r16）。

- ファインチューニングが向く場面・向かない場面についての考察：
  - 向く場面：形式（JSON のキーと型）を守らせるなど、「振る舞い」を直す場面。学習前の format_rate 0.095 が、数分の LoRA で 1.0 になった。r を 4 に下げても同じだったので、形式を覚えるだけなら少ない学習量で足りる。
  - 向かない場面：「FAQ に根拠があるか」の判断や、FAQ に無い事実を答えさせる場面。形式が整っても、根拠なしの質問に別項目を当てて断定する失敗が残った。学習データ 14 件のうち根拠なしは 4 件だけなので、「FAQ の文を返す」癖が強く付き、「FAQ に無いと判断する」部分は弱いままだった可能性がある（今回は未検証）。
  - 対策の方向：根拠なしの手本を増やして再学習する、検索（RAG）で根拠を渡す、needs_review や根拠を外側のプログラムで検証する、など。
  - 今回の限界：条件ごとに 1 回ずつの実行で、評価は 21 問。差が小さいところは、繰り返して確かめる必要がある。
